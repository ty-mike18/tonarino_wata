今回の主な更新 (v3.33):
- 食事バランスのグラフを「過去7日間」の表示に変更しました。
  ・<今日を含む過去7日間>を、左から古い順（6日前→今日）に並べます。いちばん右が今日です
  ・x軸は各日の<曜日>を表示。記録のない日も枠として残します
  ・見出しを「過去7日間の食事バランス」に変更（従来は月曜〜日曜の固定週でした）
  ・平均点はこの7日間で記録がある日だけから算出します
- コメントの表現を修正しました（記録から判断できないことを断定しない）。
  ・「今日も野菜の小鉢に手が伸びています」→「今日も副菜に手が伸びています」
    アプリが記録するのは副菜の皿数（SV）だけで、それが小鉢なのか、とんかつの
    付け合わせのキャベツなのか、牛丼の玉ねぎなのかは判別できないためです
  ・あわせて「野菜を欠かさない姿勢」→「副菜を欠かさない姿勢」に修正
  ・全コメント（1,825条件）を機械的に監査し、料理の形や個別の食品を断定している
    箇所が他にないことを確認しました（「〜を足しましょう」等の提案文は対象外）
  ・今後同種の表現が混入しないよう、検証ハーネスに専用の検出ルールを追加しました

v3.31の更新:
- 「経過」タブに睡眠アクトグラム（過去30日・ダブルプロット）を追加しました。
  ・縦軸が日付（上が30日前、下が昨晩）。1行がその日付の睡眠記録（前夜の就寝〜当日の起床）です
  ・横軸は<21時から翌21時まで>の24時間を2つ並べたダブルプロット表示
    （左半分がその日付ぶん、右半分が翌日ぶん）。21時起点にしたことで、夜間の睡眠が
    行の途中で切れず、各行の中ほどに1本の帯としてまとまって見えます
  ・睡眠時間帯を黒、<昨晩の睡眠は赤>、覚醒時間帯を白、記録のない日は薄いグレーで表示
  ・データが14日分しかなくても、過去30日の枠を常に表示します（未記録日はグレーの行）
  ・点線が日付の変わり目（0時）、実線が21時の折り返し。帯が右へ流れれば夜型化、
    階段状ならリズムの不安定さが読み取れます
  ・時間生物学で標準のダブルプロット形式のため、睡眠リズムの前後へのずれを目で追えます

v3.30の更新:
- 「SVトレーニング」を記録タブの最上部に新設しました（毎日3問のサービング数クイズ）。
  ・狙い: 利用者自身のSV認識のズレを毎日少しずつ矯正し、記録精度そのものを高める
  ・問題は全1,019問: 基本問題103問+内蔵レシピ916品から自動生成する「レシピ連動問題」
    （レシピのSV換算をそのまま出題。単一グループは「主菜およそ何SV？」、複数グループは内訳当ての複合問題）
  ・レシピ連動問題の解説にはSV内訳と目安kcalを表示し、「このレシピを見てみる」ボタンで
    レシピタブへ直行（該当レシピが開いた状態で表示）。料理名を覚える入口とレシピへの興味づけを兼ねる
  ・出題は基本問題とレシピ問題を約半々で混合。基本問題103問は食事バランスガイドのSV基準
    （主食1SV=炭水化物約40g／副菜1SV=野菜等70g／主菜1SV=たんぱく質約6g／
      乳製品1SV=カルシウム約100mg／果物1SV=約100g）に基づく出題
  ・数量問題に加え、間違えやすい分類問題（枝豆は副菜・豆乳は主菜・アイスは菓子扱い等）、
    麺類・カレーライス・親子丼・焼きそば・寿司などの複合料理の難問17問を用意
  ・6グループ（主食・副菜・主菜・乳製品・果物・複合）を1日3つずつ、2日で一巡
  ・直近45問は再出題しないため、約1か月は同じ問題に当たりません
  ・回答すると即時に正誤と「なぜそう数えるか」の解説を表示。全問終了で今日の成績と通算正答率
  ・出題・成績はすべて端末内（localStorage）で完結し、外部送信はありません
- 5つの料理グループ（主食・副菜・主菜・牛乳/乳製品・果物）の厳密な定義を記載しました。
  ・出典: 「食事バランスガイド」（厚生労働省・農林水産省決定、2005年）、フードガイド(仮称)検討会報告書
  ・各グループの主材料の定義と1SVの基準（主食=炭水化物約40g／副菜=主材料約70g／主菜=たんぱく質約6g／
    牛乳・乳製品=カルシウム約100mg／果物=主材料約100g）、および補足ルール
    （菓子・嗜好飲料と油脂・調味料は数えない／複合料理は分解して数える／大豆は主菜・枝豆は副菜 等）
  ・記録タブの皿数入力欄に折りたたみ式で常設、「利用上のご案内」には出典つきの正式版を掲載
