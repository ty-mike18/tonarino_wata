# 提出前チェックリスト

上から順に、実際に確認しながらチェックを入れてください。
**「実機で」と書いてある項目は、シミュレータでは確認になりません。**

---

## A. ビルドと動作

- [ ] `npm run build` が成功し、`ios/www/index.html` が最新の内容になっている
- [ ] `npm test` が **8 / 8 件合格** する
- [ ] `npx cap sync ios` がエラーなく終わる
- [ ] Xcode でシミュレータ起動 → 同意画面が出る
- [ ] 初回アセスメントを最後まで進められる
- [ ] 5つのタブ（ホーム・記録・経過・レシピ・案内）がすべて開く
- [ ] 食品グループの画像がすべて表示される（欠けたアイコンが無い）
- [ ] 猫のマスコットのしっぽが動く
- [ ] Xcode の警告に **赤いエラーが 0 件**

## B. 実機でのみ確認できること

- [ ] **実機で** リマインダーを ON → 通知の許可ダイアログが出る
- [ ] **実機で** アプリを完全終了しても、設定時刻に通知が届く
- [ ] **実機で** 未記録のまま設定時刻を過ぎると、アイコンにバッジ **1** が付く
- [ ] **実機で** 記録を入力するとバッジが消える
- [ ] **実機で** CSV 書き出し → 共有シートが開き、「ファイル」に保存できる
- [ ] **実機で** 保存した CSV を「CSVから復元する」で読み込める
- [ ] **実機で** 機内モードにしても全機能が動く
- [ ] **実機で** ボタンを押すと軽い振動がある
- [ ] **実機で** アプリを再起動しても記録が残っている
- [ ] **実機で** 画面下部のタブが、ホームバーに重なっていない（セーフエリア）

## C. アプリの設定（Xcode）

- [ ] **Bundle Identifier** が `capacitor.config.json` の `appId` と一致
- [ ] **Display Name** が「となりの栄養士」
- [ ] **Version** が `3.31.0`、**Build** が前回より大きい数
- [ ] **Minimum Deployments** が `iOS 15.0`
- [ ] **Signing** が「Automatically manage signing」＋正しい Team
- [ ] **Supported Destinations** から iPad を外した（iPhone のみ）
- [ ] `Info.plist` を `ios/xcode/Info.plist` で差し替えた
- [ ] `PrivacyInfo.xcprivacy` を App ターゲットに追加した
- [ ] **Push Notifications の Capability を追加していない**
- [ ] アイコン（`AppIcon-512@2x.png`）を差し替えた
- [ ] 起動画面（`splash-2732x2732*.png`）を差し替えた

## D. App Store Connect

- [ ] アプリ名が登録できた（重複していない）
- [ ] サブタイトル・概要・キーワードを入力した（`appstore/01_アプリ情報.md`）
- [ ] カテゴリを **ヘルスケア/フィットネス** にした
- [ ] **プライバシーポリシー URL** が実際に開ける
- [ ] **サポート URL** が実際に開ける
- [ ] **App のプライバシー** で「データを収集しない」と回答した
- [ ] 年齢制限のアンケートに回答した
- [ ] スクリーンショット **6.9インチ・1320×2868px を3枚以上** 登録した
- [ ] **App Review に関する情報** に審査メモを貼った（`appstore/04_審査への注記.md`）
- [ ] サインイン情報 → **不要** と回答した
- [ ] 有料で売る場合: 「有料アプリケーション」契約・銀行口座・税務情報を登録した
- [ ] 有料で売る場合: **Small Business Program** に申請した

## E. 法務・表示

- [ ] 紹介文に「治る」「効く」「改善する」などの**効果を断定する表現が無い**
- [ ] アプリ内の「利用上のご案内」に、医療行為でない旨の記載がある
- [ ] プライバシーポリシーの内容が実装と一致している（外部送信なし）
- [ ] 免責事項が読める場所にある
