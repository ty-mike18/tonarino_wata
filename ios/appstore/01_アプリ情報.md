## 3. 概要（Description）

```
「となりの栄養士」は、健康な成人の方が、毎日の食事・睡眠・体重をゆるやかに記録し、
自分の食生活を自分でふりかえるための記録アプリです。

■ 1分で終わる記録
朝食・昼食・夕食の有無と時刻、主食・副菜・主菜・乳製品・果物の皿数（SV）、
間食、体重、就寝・起床の時刻を、タップ中心で記録できます。

■ 「食事バランスガイド」にもとづく、つ(SV)の考え方
厚生労働省・農林水産省が決定した「食事バランスガイド」の区分にそって、
5つの料理グループを数えます。1SVの基準や数え方の考え方は、
アプリ内にいつでも開ける形で掲載しています。

■ 毎日3問のSVトレーニング
「この料理は主菜およそ何SV？」という短いクイズを1日3問。全1,019問。
なぜそう数えるのかの解説つきで、記録の精度そのものを少しずつ整えます。

■ オリジナルレシピ 921品
★1「買うだけ」から★4「こだわり」まで4段階。
その日の記録から足りない要素を見て、今日つくれそうな料理を提案します。
すべて本アプリのために書き起こしたオリジナルで、外部サイトへの誘導はありません。

■ 続きを見たくなる、ふりかえり
・バランススコアと日々のコメント（あなたの記録の実数を引用して語ります）
・体重の週グラフ（今週と先週を同じ曜日軸で重ねて表示）
・睡眠アクトグラム（過去30日をダブルプロット表示。夜型化やリズムの乱れを目で追えます）
・食品摂取の多様性得点（DVS）
・週に一度の定期チェックで、目標を今の体に合わせ直します

■ 記録リマインダー
設定した時刻までにその日の記録がないとき、通知でそっとお知らせします。
記録できた日には通知しません。

■ プライバシーについて
・記録はすべてお使いのiPhoneの中だけに保存されます
・アカウント登録・ログインは不要です
・外部サーバーへの送信、広告、アクセス解析は一切ありません
・インターネットに接続していなくても、すべての機能が使えます
・記録はCSVで書き出して保存でき、あとから読み込んで戻すこともできます

■ ご利用にあたって
本アプリは健康な成人の方の生活記録を支えるものであり、
病気の診断・治療・予防を目的としたものではありません。
表示される内容は一般的な情報提供であり、個別の医学的助言ではありません。
治療中の方、食事制限を受けている方、妊娠中・授乳中の方は、
かかりつけの医師・管理栄養士の指示を優先してください。
体調に不安があるときは、医療機関にご相談ください。

■ 出典
・「食事バランスガイド」（厚生労働省・農林水産省決定、2005年）
・「健康づくりのための睡眠ガイド2023」（厚生労働省）
```

## 7. App のプライバシー（Nutrition Label）の答え方

**App のプライバシー** → **開始** で聞かれる内容への回答です。

### 質問: このAppはユーザーからデータを収集しますか？

> ## → **いいえ**

以上で完了です。追加の質問は出ません。

**この回答の根拠**（もし審査で確認された場合の説明）:

- 記録データはすべて端末内の `localStorage` とアプリ専用領域のファイルにのみ保存される
- 外部サーバーへの送信処理が存在しない（`fetch` / `XMLHttpRequest` による外部通信ゼロ）
- 広告 SDK・アクセス解析 SDK を一切組み込んでいない
- Web フォントなどの外部リソースも読み込まない（端末内蔵フォントのみ使用）
- CSV の書き出しは、利用者自身が共有シートで送り先を選ぶ操作であり、自動送信ではない

## 8. 年齢制限（Age Rating）の答え方

アンケートで、次のように答えてください。**正直に答えるのが最も安全です。**

| 質問（要旨） | 回答 |
|---|---|
| 暴力・性的表現・不適切な言葉づかい | **なし** |
| ギャンブル・コンテスト | **なし** |
| **医療・医学に関する情報** | **まれ/軽度** ← 下の注を参照 |
| アルコール・タバコ・薬物への言及 | **なし** |
| ユーザー生成コンテンツ / SNS 機能 | **なし** |
| 位置情報の共有 | **なし** |
| 制限のない Web アクセス | **なし** |

> **「医療・医学に関する情報」を「まれ/軽度」にする理由**
> 体重管理の目標設定や、公的ガイドラインにもとづく食事・睡眠の目安を扱うためです。
> 「なし」と答えて後から指摘されるより、正直に申告しておく方が安全です。
> この回答だと結果は **12+**（Apple の新しい区分では **13+**）になります。
> 同種の食事記録アプリも同じ区分であることがほとんどです。
