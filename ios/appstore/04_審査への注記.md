# 審査メモと、却下されたときの返答文例

---

## 1. 提出時に貼る「App Review に関する情報」

App Store Connect のバージョンページ →「**App Review に関する情報**」→「**メモ**」欄に、
下の枠内をそのままコピーして貼ってください。**審査担当者は日本語も英語も読めますが、英語を併記すると通りやすくなります。**

```
【日本語】
本アプリは、健康な成人の方が日々の食事・睡眠・体重を記録し、ご自身でふりかえるための
記録アプリです。アカウント登録・ログインは不要で、テスト用のアカウントも必要ありません。

■ ネットワークについて
本アプリは外部サーバーと一切通信しません。レシピ・画像・文章はすべてアプリに同梱されており、
機内モードのままで全機能をご確認いただけます。データ収集・広告・アクセス解析はありません。

■ ネイティブ機能について（ガイドライン 4.2 に関して）
Webサイトの単純なラッパーではなく、以下の iOS ネイティブ機能を実装しています。
 ・ローカル通知: 利用者が設定した時刻に、その日の記録が無い場合のみ端末内で通知を予約します。
   記録済みの日は通知しません。アプリを完全に終了していても届きます。
 ・アプリアイコンのバッジ: 未記録の状態を示します。
 ・共有シート連携: 記録をCSVとして書き出し、iOSの共有シートから保存・送信できます。
 ・「ファイル」App 連携: 書き出したCSVをファイルAppから取り出し、また読み込めます。
 ・触覚フィードバック（Haptics）
 ・完全オフライン動作

■ 通知の権限について
通知の許可は、利用者が「記録」タブでリマインダーを自分でオンにしたときにのみ要求します。
起動直後には要求しません。

■ 医療性について（ガイドライン 1.4.1 に関して）
本アプリは疾病の診断・治療・予防を目的としたものではありません。
表示される内容は、日本の公的なガイドライン（厚生労働省・農林水産省「食事バランスガイド」2005年、
厚生労働省「健康づくりのための睡眠ガイド2023」）に基づく一般的な情報提供です。
医療行為ではない旨、および医師・管理栄養士の指示を優先すべき旨を、
アプリ内の「利用上のご案内」と初回の同意画面に明記しています。

■ 確認手順
 1. 同意画面で内容を確認し「同意する」をタップ
 2. 初回アセスメント（ニックネーム・年齢・身長・体重・活動量・目標）を入力
 3. 「記録」タブで食事の皿数を入力すると、ホームにスコアとコメントが表示されます
 4. 「記録」タブ下部のリマインダーをオンにし、時刻を数分後に設定してアプリを終了すると、
    通知が届くことをご確認いただけます

【English】
This app is an offline food/sleep/weight journal for healthy adults. No account or login is
required, so no demo account is needed.

Network: The app makes no network requests at all. All recipes, images and text are bundled.
It works fully in Airplane Mode. No analytics, no ads, no data collection.

Native functionality (re: Guideline 4.2): This is not a repackaged website. It implements
local notifications (scheduled on-device, only when the day has no entry; delivered even when
the app is fully terminated), app icon badging, iOS share sheet export of CSV, Files app
integration, haptic feedback, and complete offline operation.

Notification permission is requested only when the user explicitly enables the reminder in the
"記録" (Record) tab — never at launch.

Medical (re: Guideline 1.4.1): The app does not diagnose, treat, or prevent any disease.
Content is general information based on Japanese public guidelines (the "Japanese Food Guide
Spinning Top" by MHLW/MAFF, 2005, and the MHLW Sleep Guide 2023). A disclaimer stating that
this is not medical advice, and that users should follow their physician's or registered
dietitian's instructions, is shown on the consent screen and in the in-app "利用上のご案内".
```

**サインイン情報が必要ですか？** → **いいえ**（ログイン機能がないため）

**連絡先** → 自分の氏名・電話番号・メールアドレスを入力（審査担当者からの連絡用。公開されません）

## 2. 却下されたときの返答文例

却下されると **Resolution Center** にメッセージが届きます。
慌てず、指摘された **ガイドライン番号** を確認してから、下の文例を使ってください。

### 2-1. 「4.2 Minimum Functionality」で却下された場合

> 指摘の趣旨: 「Web サイトを包んだだけのアプリに見える」

**あわせて動画を添付してください。** iPhone の画面収録で、
「リマインダーをオンにする → アプリを完全終了する → 通知が届く」までの30秒ほどを撮り、
Resolution Center に添付すると一度で通ることが多いです。

```
Thank you for the review.

We would like to clarify that this app is not a repackaged website. It is a fully offline
iOS application whose core value depends on native iOS capabilities:

1. On-device local notifications (UNUserNotificationCenter)
   The app schedules up to 14 days of reminders on the device. Each reminder is re-evaluated
   whenever the user saves an entry: the notification for a day that already has a record is
   cancelled automatically. These notifications are delivered even when the app is fully
   terminated. This behaviour is impossible in a web page.

2. App icon badging
   The icon badge reflects whether today's entry is still missing, and clears the moment the
   user records a meal.

3. iOS share sheet and Files app integration
   Exported CSV records are written to the app container and passed to UIActivityViewController
   so the user can save them to Files, AirDrop them, or mail them. The app also declares
   UIFileSharingEnabled and LSSupportsOpeningDocumentsInPlace.

4. Automatic on-device backup and recovery
   Records are mirrored to a JSON file in the app's Library directory and restored automatically
   if web storage is ever evicted — protecting user data in a way a website cannot.

5. Complete offline operation
   The app performs zero network requests. All 921 recipes, 1,019 quiz questions, images and
   text are bundled in the binary. It is fully functional in Airplane Mode.

6. Haptic feedback on interactions.

We have attached a screen recording demonstrating item 1: enabling the reminder, terminating
the app from the app switcher, and receiving the notification.

Please let us know if any further information would help.
```

### 2-2. 「1.4.1 / 健康関連」で却下された場合

> 指摘の趣旨: 「医療的な主張をしていないか」「不正確な健康情報ではないか」

```
Thank you for the review.

This app does not diagnose, treat, cure, or prevent any disease, and it makes no such claims.
It is a self-monitoring journal for healthy adults.

All guidance shown in the app is general dietary and sleep information derived from Japanese
government publications:
  - "Japanese Food Guide Spinning Top" (食事バランスガイド), decided jointly by the Ministry of
    Health, Labour and Welfare and the Ministry of Agriculture, Forestry and Fisheries, 2005
  - "Sleep Guide for Health Promotion 2023" (健康づくりのための睡眠ガイド2023), MHLW

The app displays the following disclaimer on the consent screen shown before first use, and
again in the in-app "利用上のご案内" (About) section:
  - This app is intended for healthy adults and is not a medical device.
  - The content is general information, not individualised medical advice.
  - Users under treatment, on a prescribed diet, pregnant, or breastfeeding should follow the
    instructions of their physician or registered dietitian.
  - Users should consult a medical institution if they have any health concerns.

Energy targets are calculated from standard published equations and are floored at 1,200 kcal
and at the user's basal metabolic rate; users classified as underweight cannot select a
weight-loss goal. These safeguards are enforced in the input validation.

Please let us know which specific screen or wording you would like us to revise.
```

### 2-3. 「2.1 App の完全性 / 情報不足」で却下された場合

> 指摘の趣旨: 「動作が確認できない」「機能の説明が足りない」

まず、**どの画面で止まったのか**を Resolution Center で尋ねてください。
多くの場合、初回の同意画面と初回アセスメントを通過できていないことが原因です。

```
Thank you for the review. Here is the exact path to reach the main functionality:

1. On launch, a consent screen appears. Scroll to the bottom, tick the checkbox, and tap
   the green "同意する" button.
2. The initial assessment appears. Enter any nickname, then age (18-100), height (120-220 cm),
   weight (30-200 kg), select an activity level and a goal, and tap the green button at the
   bottom of each step.
3. You will land on the Home tab. Tap the second tab "記録" (Record) at the bottom.
4. Enter any number of servings for 主食 / 副菜 / 主菜 and tap the green save button.
5. Return to the Home tab to see the score and generated comment.

No account, password, or network connection is required at any point.
```

### 2-4. 「5.1.1 データ収集」で却下された場合

```
Thank you for the review.

This app collects no data whatsoever. There is no analytics SDK, no advertising SDK, no
crash reporting service, and no network request of any kind in the binary. All user entries
are stored only in the app's own container on the device (localStorage plus a JSON backup file
in the app's Library directory) and are removed when the app is deleted.

Accordingly, our App Privacy answer is "Data Not Collected", and our privacy policy at
https://ty-mike18.github.io/tonarino_wata/privacy.html states the same.

CSV export is a user-initiated action that opens the iOS share sheet; the destination is
chosen by the user, and nothing is transmitted automatically.
```

## 3. 返答するときのコツ

- **感情的にならない。** 事実だけを、番号を振って簡潔に書く
- **必ず英語で書く。** 日本語だけだと翻訳待ちで往復が増える
- **証拠を添える。** 画面収録の動画が最も効く（30秒で十分）
- **1往復で終わらせるつもりで書く。** 聞かれていないことも先回りして書く
- 修正が必要な指摘なら、**素直に直して再提出する方が早い**
