# スクリーンショット撮影ガイド

App Store のページに載せる画像です。**ここで9割の人がインストールするかを決めます。**
とはいえ、凝ったデザインは審査の必須条件ではありません。まずは「そのまま撮る」で十分です。

---

## 1. 必要なサイズと枚数

| 項目 | 内容 |
|---|---|
| **サイズ** | **1320 × 2868 px**（6.9インチ・縦） |
| **枚数** | **3枚以上**（最大10枚） |
| **形式** | PNG または JPEG（透過なし） |

**このサイズ1種類だけ用意すれば、他の画面サイズには Apple が自動で適用します。**
（iPad 対応を外していれば、iPad 用は不要です）

---

## 2. いちばん確実な撮り方（シミュレータ）

### 手順

1. Xcode で機種を **iPhone 16 Pro Max**（または 17 Pro Max などの 6.9インチ機種）にする
2. ▶ を押してシミュレータで起動する
3. **撮りたい画面まで進める**（下の「撮る画面」参照）
4. シミュレータのメニュー → **File** → **Save Screen Shot**（⌘S）
5. デスクトップに PNG が保存される

### サイズを確認する

保存した PNG を選んで **⌘I**（情報を見る）で、**1320 × 2868** になっていることを確認します。

違うサイズだった場合は、機種の選び直しか、次のコマンドでリサイズしてください。

```bash
sips -z 2868 1320 ~/Desktop/Simulator*.png
```

> 実機で撮る場合、iPhone 16 Pro Max / 17 Pro Max なら
> そのままのサイズ（1320×2868）で使えます。それ以外の機種は上のコマンドでリサイズしてください。

## 3. 撮る画面（おすすめの5枚）

順番も大事です。**1枚目で「何のアプリか」が伝わるように**します。

| # | 画面 | どこで撮るか | 伝えたいこと |
|---|---|---|---|
| **1** | **ホーム（スコアとコメント）** | 数日ぶん記録したあとのホームタブ | 毎日ふりかえれる |
| **2** | **記録タブ** | 皿数の入力欄が見える位置 | 1分で終わる手軽さ |
| **3** | **経過タブ（体重グラフ・アクトグラム）** | 経過タブを下にスクロール | 続けると見えてくるもの |
| **4** | **レシピタブ** | 「今日のおすすめ」が並ぶ位置 | 921品のレシピ |
| **5** | **SVトレーニング** | 記録タブ最上部のクイズ | 学べる要素 |

### 撮る前の下ごしらえ

**空っぽの画面を撮らないでください。** 記録が入っていないと、
グラフもコメントも出ず、魅力が伝わりません。

シミュレータで **5〜7日ぶんのダミー記録**を入れてから撮ることをおすすめします。
手で入力してもよいですが、Safari の Web インスペクタから流し込むこともできます
（マニュアル STEP 8-3 の手順でコンソールを開き、`localStorage` に直接書き込む）。

> **ニックネームに本名を入れないでください。** スクリーンショットは公開されます。
> 「あおい」「けんた」など、架空の名前にしてください。

## 4. あると良い加工（任意）

各スクリーンショットの上部に、**短い説明文**を重ねると訴求力が上がります。

| # | 入れる文字（例） |
|---|---|
| 1 | 毎日1分、食事と睡眠を記録 |
| 2 | 皿数を数えるだけ。カロリー計算は不要 |
| 3 | 体重も睡眠も、続けるほど見えてくる |
| 4 | オリジナルレシピ 921品を内蔵 |
| 5 | 毎日3問、SVの感覚が身につく |

**注意: 効果を断定する表現は使わないでください。**
「痩せる」「healthy になる」「改善する」などは、審査でも景品表示法でも問題になります。

無料でできる加工の方法:

- **Keynote**（Mac に標準搭載）: スクリーンショットを貼って、上にテキストボックスを置き、
  スライドサイズを 1320×2868 にして画像で書き出す
- **Canva**（Web・無料枠あり）: 「App Store スクリーンショット」のテンプレートがある
- **プレビュー.app**: 文字入れだけなら、マークアップ機能でも足りる

---

## 5. App プレビュー（動画・任意）

15〜30秒の動画も登録できますが、**必須ではありません**。
最初のリリースでは省略して構いません。

作る場合は、シミュレータの **File → Record Screen** で撮り、
15〜30秒、1320×2868 に収めてください。

## 6. 提出前の確認

- [ ] 3枚以上ある
- [ ] すべて 1320 × 2868 px
- [ ] 本名・実在のメールアドレスが写り込んでいない
- [ ] 記録が入った状態で撮っている（空の画面がない）
- [ ] 実装されていない機能を見せていない（審査の 2.3.3 に抵触します）
- [ ] 文字を重ねた場合、効果を断定する表現になっていない
- [ ] 1枚目だけを見て「何のアプリか」が分かる
